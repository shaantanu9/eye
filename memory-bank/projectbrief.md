# EYE Project Brief

## Project Overview
**EYE** is an open-source AI-first computer vision workspace designed to preserve memories and enable intelligent conversations with personal photo/video collections. The system transforms traditional photo storage into an intelligent memory vault where users can have natural language conversations about their personal history.

## Core Mission
"Preserve memories. Have intelligent conversations."

## Key Value Propositions
1. **Memory Preservation**: Transform photos/videos into searchable, intelligent memories
2. **AI-Powered Understanding**: Advanced computer vision and LLM integration for context understanding
3. **Privacy-First**: Local processing with no cloud dependency
4. **Open Source**: Community-driven development with MIT license
5. **Accessibility**: Three-tier system (Light/Heavy/God Mode) for different compute capabilities

## Target Users
- **Primary**: Individuals wanting to preserve and interact with personal photo collections
- **Secondary**: Developers and researchers working with computer vision
- **Tertiary**: Organizations needing local AI processing capabilities

## Core Features
- **Memory Ingestion**: Drag & drop upload with batch processing
- **AI Understanding**: Visual recognition, scene understanding, emotional context
- **Intelligent Conversations**: Natural language interface for memory exploration
- **Smart Search**: Semantic search with time-based filtering and person recognition
- **Privacy Protection**: Local AI processing with end-to-end encryption
- **Open Source**: Extensible architecture for community contributions

## Technical Architecture
- **Backend**: FastAPI with Python, PostgreSQL, Redis, MinIO
- **Frontend**: Next.js with TypeScript, Tailwind CSS
- **AI/ML**: YOLO-E for object detection, Ollama for LLM processing
- **Infrastructure**: Docker Compose with GPU support
- **Storage**: MinIO for object storage, FAISS for vector search

## Development Status
- **Current State**: Early development phase with core infrastructure in place
- **Timeline**: 4-8 weeks to reach usable state
- **Priority**: Focus on core memory processing and AI integration
- **Community**: Open source with active development roadmap

## Success Metrics
- User adoption of memory preservation features
- Quality of AI-generated memory descriptions
- Community contributions and engagement
- Performance across different hardware configurations
